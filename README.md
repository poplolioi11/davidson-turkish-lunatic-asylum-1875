# 奧斯曼精神病院訪記（1875） / A Visit to a Turkish Lunatic Asylum — Transcription Dataset

英國醫師 John H. Davidson 於 1875 年刊行的奧斯曼精神病院訪記，記載君士坦丁堡 Üsküdar 一帶的病房、照護人員、院內生活與收治情形。這份單獨印行的《Journal of Mental Science》抽印本，可用於比較十九世紀的精神醫療與機構照護。

Published in Lewes in 1875, John H. Davidson’s visit to a psychiatric hospital in the Üsküdar area of Constantinople records wards, staff, patients, and everyday conditions. This offprint from the Journal of Mental Science documents a British physician’s observations of Ottoman institutional care.

## Source and scope

Yale University, Harvey Cushing/John Hay Whitney Medical Library, b21028059, Source frames 1–20. Original imprint: G. P. Bacon, Lewes, 1875. The 20-frame copy includes the original cover, title leaf and eight printed pages. One marked omission occurs in the text. Blank scans and later library marks are inventoried.

## Files

- `transcription.txt` retains line and frame markers. Tabs mark table cells. 
- `transcription.json` identifies each frame and text or table unit. A null printed page means no printed page number was recorded. The source links identify the corresponding scan.
- `transcription.tei.xml` maps the same frame text and table cells into TEI P5.
- `review-notes.md` lists review coverage and reading decisions.
## Transcription and review

AI-assisted reading used fixed source scans. Published text preserves printed spellings and historical terminology. Spacing may be normalized. A square (□) indicates an unresolved character. See the notes for editorial omissions and uncertain readings.

Version 0.1.0. This dataset has no measured error rate or expert proofreading.
